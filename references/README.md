# Reference library

This collection contains the 26 supplied source files and the current **Queens Venture Capital Planning Document**, dated 23 September 2026. Each original has been copied without changing its contents. The public catalogue is in [`../data/reference-library.json`](../data/reference-library.json), including the original filenames, file sizes and SHA-256 checksums.

The planning document supplies the current interpretation of the wider archive. The archive includes earlier thought experiments, working drafts, financial guides, historical event dates and speculative research concepts. Their presence records the development of the proposal. It does not establish that a programme, investment fund, government partnership or technical capability exists.

The original files retain their original formatting, links and references. Some working documents include local links or draft citation markers that will not resolve on the public website. Their source bytes are preserved rather than silently repaired.

The 120-entry enterprise catalogue is derived from **500 Queens VC NEW Long**, slides 15-18, with the current plan providing context and suggested mentorship routes. Original titles and categories are retained, with whitespace normalised. Where the plan adjusts spelling or expands an abbreviation, the catalogue retains both forms.

External sources and pre-existing source materials retain their own rights. The website's Strange But True licence does not grant rights over independently owned third-party material.
